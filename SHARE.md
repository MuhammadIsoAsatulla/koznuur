# Sharing KoʻzNur

For a new deployment, follow [the Vercel and inference API setup](DEPLOYMENT.md). Share your deployed frontend URL after testing an upload from that origin.

For a demonstration on the machine running KoʻzNur, open [the local app](http://127.0.0.1:8000), select a sample or upload a retinal photograph, then use the heatmap switch to inspect the result.
